🐹 MOLE MAYHEM

An Interactive Whack-a-Mole Game | C + Raylib

MOLE MAYHEM is a 2D arcade-style Whack-a-Mole game developed in C using the Raylib graphics library.

Choose your map, select your difficulty, test your reflexes, and compete for the highest score!

🎮 Features

- 5 Game Environments: Night, Village, Day, Sunset and Fence.
- Random Map Selection: Let the game choose your environment.
- 3 Difficulty Levels: Easy, Medium and Hard.
- Player Registration & Login: Create an account or log in.
- Score Tracking: Save and view individual player scores.
- Leaderboards: Compete for the top three scores in each difficulty.
- Interactive Gameplay: Click on appearing moles to earn points.
- Lives System: Avoid missing too many targets!

🛠️ Built With

- C Programming Language
- Raylib Graphics Library
- GCC Compiler
- Git and GitHub

📂 Project Structure

File| Description
"main.c"| Main loop, menus and map/difficulty selection
"game.c"| Core gameplay, mole movement, collision detection and scoring
"login_register.c"| Player registration and login
"scores.c"| Leaderboards, player scores and game-over screen
"*.png"| Game backgrounds, moles and interface graphics
"music.mp3"| Background music
"*.txt"| Player and score data files

🚀 Getting Started

Option 1: Download the Game

1. Visit the "MOLE MAYHEM repository" (https://github.com/Navdeep726/MOLE-MAYHEM).
2. Click the green Code button.
3. Select Download ZIP.
4. Extract the downloaded folder.
5. Run the available Windows executable, if compatible with your system.

Option 2: Run from Source Code

To build the project yourself, you will need:

- GCC compiler
- Raylib library
- Windows development environment (for the supplied Windows configuration)

Clone the repository:

git clone https://github.com/Navdeep726/MOLE-MAYHEM.git

Open the project folder in your preferred C development environment.

Configure Raylib and compile the project using the appropriate source files and linker settings.

Note: The source build instructions should be finalized after verifying all required header files and function declarations.

🕹️ How to Play

1. Launch the game.
2. Register or log in.
3. Select a map or choose Random.
4. Choose Easy, Medium or Hard.
5. Click on the moles as they appear.
6. Earn points while keeping your lives.
7. Try to secure a place on the leaderboard!
